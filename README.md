# Field of View

Personal portfolio of Mohamed Ibrahim, AI Engineer (agentic systems and applied computer vision).

The site is seen through a vision model's eyes: a depth-mapped point cloud portrait, bounding boxes,
real telemetry, and live demos that run in the visitor's browser.

- `apps/web`: Next.js site (Vercel)
- `apps/api`: FastAPI (Vercel Python Functions): AI twin, recruiter mode (via Mizan), contact
- `tools`: offline scripts (portrait to points, ONNX export, video compression)
- `docs`: the original brief, the decisions log, the content checklist

Working notes for contributors and agents are in `CLAUDE.md`.
